ABOUT THE PROJECT

Where agriculture meets intelligent insight.

CropWise is a machine-learning based crop recommendation project that explores how soil nutrients and environmental conditions can be used to predict a crop category.

Academic microproject Machine learning
✳ Rooted in data Designed around seven input features

WHY CROPWISE

A focused idea with a practical purpose.

Choosing a crop involves understanding several conditions. CropWise demonstrates how a machine-learning model can learn patterns from labelled agricultural data and use those patterns to predict a crop category from new input values.

The project brings data preparation, exploratory analysis, model comparison and a simple web interface together in one educational application.

PROJECT SCOPE

A prediction tool, not a complete farm advisory system.

CropWise predicts one of the 22 crop categories represented in its dataset. The selected dataset does not include every factor involved in real farming decisions, such as geographical location, soil type, season, irrigation availability, market conditions or expected yield. The prediction should therefore be understood as an educational, data-driven output rather than a guarantee of agricultural suitability.
